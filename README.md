# Paul's Dotfiles (NixOS)
NixOS and HomeManager with flakes (work in progress)

## Organization
* configuration.nix - just enough to get a working desktop environment going
* home.nix - all the bells and whistles

## Packages
* Desktop Environment - hyprland
  * including hypr ecosystem apps
* Terminal - kitty
* Editor - nvim (work in progress to get plugins playing nicely)
* Emphasis on TUI apps instead of GUI
